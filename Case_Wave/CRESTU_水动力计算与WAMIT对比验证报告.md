# CRESTU 水动力计算与 WAMIT 对比验证报告

## 1. 验收结论

本轮完成了代码模块化文档重构、16 频点计算、按频率重建外域、势函数缓存重载、单体三网格算例、
双体 12 自由度算例、平均漂移四项近场积分与 Kochin 远场积分，以及独立绘图和数据表导出。

| 项目 | 状态 | 结论 |
|---|---:|---|
| MATLAB 语法与静态检查 | 通过 | 69 个 MATLAB 文件，最终 `checkcode` 无问题 |
| 频率与浪向 | 通过 | 16 点 `0.5:0.1:2.0 rad/s`，浪向 `0/45/90 deg` |
| 势函数缓存 `IPOTEN=0` | 通过 | 单体三网格与双体均完成缓存后处理，结果结构版本为 5 |
| 单体中频阻尼异常 | 通过 | `omega=1` 时 `B33` 相对 IRR3 误差由数量级异常降至 4.94% |
| 单体全频段精度 | 部分通过 | 中频良好，高频阻尼、激励和 RAO 仍明显退化 |
| 双体 12 自由度尺寸与有限值 | 通过 | `A/B: 12x12x16`，RAO 覆盖 12 DOF、3 浪向、16 频点，无 NaN/Inf |
| 双体 WAMIT 数值一致性 | 未通过 | 自项中频可用，交叉附加质量误差仍约 85%--91% |
| 二阶平均漂移 | 未通过 | 公式与诊断项已实现，但近场、远场均未与 WAMIT 收敛 |

因此，本代码已具备可重复运行和诊断能力，但不能宣称二阶漂移或双体交叉耦合已经通过工程验证。

## 2. 主要修正

1. 每个频率单独按照波长重建自由液面、海底和远场网格，保证吸收层宽度不小于 `1.5 lambda`；
   避免用 `omega=0.5` 的超大外域承载全部频率所造成的中频离散不足。
2. 保留动态 Rayleigh 吸收参数、每频率环境统计和版本化势函数缓存。
3. 附加质量与阻尼输出施加最近 Frobenius 范数的互易投影；双体最终矩阵满足 `A=A^T`、`B=B^T`。
   投影前最大相对残差为：附加质量 0.02785，近场压力阻尼 0.24207；最终采用的能量阻尼本身对称。
4. 近场漂移采用有权二次移动最小二乘重建速度与 Hessian，并修正水线方向、相对波高、激励力旋转项和
   平移压力梯度项；每个贡献项均独立保存。
5. 远场漂移修正外部流体域法向符号、对角共轭配对系数和偏航力矩配对，并统一 WAMIT 无量纲尺度：
   `Cd = F2 / (0.5 rho g A^2 L)`，本报告取 `L=10 m`。

## 4. 二阶平均漂移验证

以迎浪水平漂移系数为例：

| omega (rad/s) | Near-field Cd | Far-field Cd | WAMIT pressure Cd | WAMIT momentum Cd |
|---:|---:|---:|---:|---:|
| 0.5 | 0.003020 | -0.001622 | 0.000000919 | 0.000000464 |
| 0.8 | 0.118969 | -0.005392 | 0.000112 | 0.0000847 |
| 1.0 | 0.426615 | 0.025211 | 0.002009 | 0.001644 |
| 1.2 | 1.419324 | 0.047372 | 0.032173 | 0.030903 |
| 1.4 | 9.132532 | -2.305190 | 0.451321 | 0.515338 |
| 1.6 | 0.650131 | -0.282989 | 0.568031 | 0.778206 |
| 1.8 | 0.189570 | -0.037134 | 0.394078 | 0.639889 |
| 2.0 | 0.100450 | -0.003864 | 0.335542 | 0.637926 |

`omega=1` 时，Near-field/WAMIT-pressure 约为 212 倍，Far-field/WAMIT-momentum 约为 15.3 倍。
该差异不能通过无量纲系数或长度尺度解释。近场水线项在中频后出现非物理峰值，远场 Kochin 相位/幅值也尚未
达到 Newman 动量结果。后续必须以规则波自由面升高、物面切向速度和 Kochin 圆柱通量的独立解析算例逐项核验，
不能采用经验缩放掩盖误差。

## 6. 对称性基准

| 网格 | 未知数 | 全域等效面板 | 运行时间 (s) | 加速比 | A/B/F 相对差最大值 |
|---|---:|---:|---:|---:|---:|
| Full | 740 | 740 | 2.413 | 1.000 | 0 |
| Half-X | 370 | 740 | 2.283 | 1.057 | 2.28e-16 |
| Quarter-XY | 185 | 740 | 2.234 | 1.080 | 3.36e-16 |

未知数严格降为 1/2 和 1/4，数值重构达到机器精度。小规模 MATLAB 算例的总时间主要受 JIT、网格准备和
后处理固定成本控制，因此实测加速比明显小于矩阵规模的理论加速；大型网格才会显示 LU 降阶优势。

## 7. 运行方法

在 MATLAB 中将当前目录切换到 `Code/`：

```matlab
addpath('Case_Wave');
validation = Run_All_Validation(false);  % Load compatible caches and regenerate tables/figures
validation = Run_All_Validation(true);   % Recompute all potential-flow cases
```

也可分别运行：

```matlab
addpath('Case_Wave/Case1_SingleSphere_Convergence');
Run_SingleSphere_Convergence(false);

addpath('Case_Wave/Case2_TwoSpheres_Interaction');
Run_TwoSpheres_Interaction(false);

addpath('Case_Wave/Common_Scripts');
Plot_SingleBody_Results;
Plot_MultiBody_Results;
Plot_MeanDrift_Comparison;
```

绘图脚本均可独立载入缓存，使用中文标题、坐标轴、图例、网格，并导出 300 DPI PNG。
