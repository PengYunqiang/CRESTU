# CRESTU-2D for P2 Appendix A

This MATLAB package contains the CRESTU-2D high-frequency radiation solver and the two verification cases described below. The high-frequency boundary-value problem sets the potential to zero at the free surface and imposes zero normal velocity at the bottom in finite depth. The transverse coordinates are `(y,z)` with `z` up. The degree-of-freedom order is sway, heave and roll about `+x`. The heave added mass `A(2,2)` is in kg/m.

## Reproduce the Appendix A checks

Test environment: MATLAB R2023b Update 10. Open a fresh MATLAB session in the package root and run the following commands. Both geometries are generated by the scripts.

```matlab
addpath(fullfile(pwd, 'research', 'p2_hf'));
summary = run_appendix_a(fullfile(pwd, 'hf_results'));
```

Use a new output directory for each run. The script writes `analytic_circle.csv`, `rectangle_refinement.csv` and the 76 individual rectangular BEM results under `table/`.

- **Half-immersed circular cylinder.** Radius 1 m, density 1025 kg/m³, deep water. The exact heave added mass is `rho*pi*R^2/2` = 1610.06623496477 kg/m. The 32, 64, 128 and 256 panel sequence gave a finest relative error of approximately `1.0543e-8`. The pre-defined acceptance limit is 0.005.
- **Rectangular sections.** Widths 7 and 10 m, 19 positive drafts for each width from 0.2 to 15 m, density 1025 kg/m³ and water depth 420 m. Each of the three wetted edges uses 64 and 128 cosine-spaced panels. The maximum relative change `abs(A128/A64-1)` over the 38 paired nodes was approximately `0.00069431` (0.069431%). The pre-defined limit is 0.005. The script also applies the original fine-grid residual, reciprocity and scaled minimum-eigenvalue checks.

The reproducibility scope is the analytical cylinder comparison and the rectangular BEM refinement. The separate comparison with the P2 frozen finite-volume table and the independent finite-volume reruns require research assets outside this package.

## Solver entry points

Run a single rectangular high-frequency case from the package root.

```matlab
r = CRESTU_2D_HF(7, 7);
disp(r.A(2,2));  % kg/m
```

`CRESTU_2D_HF.m` calls `source/2d/+crestu2d/hf_solve.m`. For a separate finite-frequency 2-D example, run `CRESTU_2D('examples/2d/semicircle.c2d.json')`. That example saves results under `results/2d/semicircle`.
