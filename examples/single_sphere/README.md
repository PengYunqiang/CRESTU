# Canonical single-sphere example

This directory contains the small release example used by `run_example_single_sphere` and `run_validation_smoke`.

- `Case1_Smoke.cfg` runs one frequency at `omega=1.2 rad/s` and one heading.
- `Case1_Fine.cfg` is the full 16-frequency Fine configuration.
- `hemi_D10_fine_body.bmf` is the canonical body input.

Generated free-surface/seabed/far-field meshes, cache, results, and logs are intentionally ignored by Git.
